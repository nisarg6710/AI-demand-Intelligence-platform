# Customer Review AI Platform

An end-to-end MLOps and Full Stack AI application that analyzes customer reviews using Natural Language Processing and Machine Learning.

Features:

- Data ingestion pipeline
- Data validation
- Feature engineering
- Model training
- Experiment tracking
- REST API deployment
- Interactive dashboard
- CI/CD integration
- Cloud deployment

Tech Stack:

- Python
- PyTorch
- Hugging Face
- FastAPI
- Streamlit
- MLflow
- DVC
- Docker
